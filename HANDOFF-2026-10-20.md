## 2. TinyFish integration (what exists in code now)

Read the commits for the exact diffs: `git log --oneline a2432c0^..HEAD` in the repo.

| Capability | TinyFish endpoint | Where it plugs in |
|---|---|---|
| Search | `GET https://api.search.tinyfish.ai` (`query`, `language`, `purpose`) | `src/app/api/tinyfish/search/route.ts`; scanner page: a name with no "." triggers "Find pages" |
| Fetch | `POST https://api.fetch.tinyfish.ai` (`urls[≤10]`, `format:"markdown"`, `ttl:0`) | `src/app/api/scanner/analyze/route.ts`: text is appended to `perception.visibleText` before `classifyPage` |
| Browser | `POST https://api.browser.tinyfish.ai` → `session_id`, `cdp_url`; `DELETE /{session_id}` | `src/server/browser/manager.ts`: `browserFor(url)` picks the cloud or local browser; one shared cloud browser with one context per session |
| Web Agent | `POST https://agent.tinyfish.ai/v1/automation/run-sse` (`url`, `goal`) | `src/app/api/tinyfish/agent/route.ts` streams NDJSON to `src/components/tinyfish/TinyFishAgentPanel.tsx` on `/agent` |

All calls use the `X-API-Key` header.

**Core files**
- `src/server/tinyfish/client.ts`: all four APIs, the `TinyFishCall` recorder, the SSE parser, `reachableFromCloud()`, and `CANCEL_GOALS.explore` / `CANCEL_GOALS.confirm`.
- `src/app/api/tinyfish/status/route.ts`: returns `{enabled, demoUrl}`.
- `src/lib/services/tinyfishService.ts` (client side) and `src/components/tinyfish/TinyFishActivity.tsx` (the panel listing API, status, ms and id).
- `scripts/tinyfish-smoke.ts`, run with `npm run tinyfish:smoke`: one live call per API.
- Rate limits in `src/server/security/rate-limit.ts`: `tinyfishSearch` 60/hour, `tinyfishAgent` 10/hour.
- The agent runner emits a case-log event saying which browser it used (`src/server/agent/runner.ts`).

**Facts learned from probing the live APIs**
- **SSE format:** `data: {"type":"STARTED"|"STREAMING_URL"|"PROGRESS"|"COMPLETE", run_id, streaming_url, purpose, status, result}`. A plain-text answer arrives as `result.result`.
- **No `max_steps`:** `agent_config.max_steps` returns **403**, because the account isn't in the beta. Don't send it.
- **Browser:** `browser.newContext()` works over CDP. Creating a session takes about 3 s in practice.
- **Live view:** the `streaming_url` expires when the run ends. It embedded fine in an iframe; an "open in new tab" link is provided as a fallback.
- **Search on "StreamVault"** returns unrelated real sites, which is expected: our test site isn't indexed.

**Env vars** (documented in `.env.example` and `README.md`)
- `TINYFISH_API_KEY`: **REDACTED.** It's in `.env.local`, which is git-ignored. The key was pasted in chat, so **advise the user to rotate it.**
